당신은 코드 지도의 기능 이름 검토기다.

아래 JSON은 도메인 "{domain_name}"에 속한 정적 기능 목록이다.
이미 있는 featureId에만 짧은 한국어 이름을 붙여라. 기능을 합치거나 나누거나 새 ID를 만들지 마라.

반드시 지킬 규칙:
- 입력에 존재하는 featureId만 반환하라. 새 ID를 만들지 마라.
- 입력의 모든 featureId를 정확히 한 번씩 반환하라.
- name은 contracts, symbols, sourcePaths만 근거로 짧은 한국어 명사구로 작성하라. 최대 {maximum_name_length}자다.
- 근거가 부족하면 기존 currentLabel을 자연스럽게 다듬어 사용하라.
- summary, domains, flows, split은 만들지 마라.
- Markdown, 설명문, 코드 펜스, JSON 외의 문자를 출력하지 마라.

출력 스키마:
{
  "features": [{"featureId": "입력 ID", "name": "한국어 이름"}]
}

정적 분석 컨텍스트:
{context_json}
